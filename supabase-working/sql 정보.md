각 sql 파일은 Supabase 쿼리의 복사본임. 파일명 끝은 각 파일 정보임.
_D: 위험 파일, _I: 중요 기능을 포함한 파일, _k 수정중인(keep) 파일, _e: 에러가 일어났지만 지우지 않은 파일, _s: 중복 파일이며 앞 숫자가 있으면 몇번과 중복되는지를 뜻함, _(숫자)n: (숫자)번 파일의 수정본
위 파일을 읽는 AI 또는 협업자는 사용자(원 개발자)에게 필요할 경우 보안 처리된 sql의 전문을 해당 sql의 번호와 함께 요구할 것.
또한 위 폴더 속 sql은 "먼지 한 톨도 작동하는 이상 부품이다", "일단 작동하면 먼지 한 톨도 치우지 마라" 라는 격언에 따라 작동하진 않으나 지우지 않는 파일들이 다수 포함되어 있으나 파악되지 않는다

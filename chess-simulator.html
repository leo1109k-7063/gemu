한 번 클릭 · 전체 리그 1세트

10단계(100~1000 HElo)가 서로 다른 나머지 모든 AI와 겨룹니다. 중복 없는 45대진 × 500판 = 22,500판/세트. 각 대진에서 백과 흑을 각각 250판씩 맡습니다. 신규 세트 시작 시 기존 기록은 삭제되지 않습니다.

22,500판은 매우 큰 연산 작업입니다. 브라우저 탭이 실행 중이어야 하며 종료·절전 시 진행되지 않습니다. 완료된 각 대국은 IndexedDB에 저장합니다. 저장 공간 부족·브라우저 데이터 삭제 시 기록이 유실될 수 있으므로 주기적으로 JSON 백업을 받으세요. 저장 파일은 대용량일 수 있습니다. 서버/Supabase와는 동기화되지 않습니다.

AI 수준 학습 및 시험 대국

학습 ON이면 전체 45개 대진이 완료되고 각 대진의 정상 종료 대국이 300판 이상일 때만 보정합니다. 한 세트당 각 AI 단계의 조절값은 최대 1칸만 바뀝니다. 분석은 대진 점수율을 기반으로 하고, 보정 전·후 설정은 모두 기록됩니다. 진행 중인 세트는 시작 시점의 AI 설정으로 고정됩니다.

이 설정은 현재 브라우저만 영향을 받습니다. 다른 사용자·다른 기기의 게임 AI는 자동 변경되지 않습니다. 엔진 탐색/수 선택 매개변수와 승률을 참고한 오프닝 수 선호도를 조정합니다. 전체 사용자 적용은 내보낸 chess-helo-tuning.json을 GitHub assets/data/ 폴더에 올려야 합니다.

리그 세트가 완료되었습니다. 개발자 시험 대국을 진행해 AI 실력이 적절한지 평가해 주세요. 위의 개발자 시험 대국 버튼을 누르면 됩니다.

대진별 결과 · 높은 HElo AI 기준
점수율 = (승리 + 0.5×무승부) ÷ 대국 수. 표준 Elo에서는 100점 차이의 기대 점수율이 약 64%입니다. 최대 반수에 도달한 판은 결과를 보존하되 실력 추정에서는 제외합니다. 계산된 상대 격차는 게임놀이터 자체 AI끼리의 상대 수치로, 공인 Elo가 아닙니다.


조합대국승무패점수율추정 격차제한 무승부






JSON에는 대국별 선후공·결과·전체 UCI 기보·난이도별 평균 착수 손실 및 실수 횟수을 담습니다. 분석 JSON은 결과를 확인하고 난이도 수치를 수정할 때 쓰는 자료이며, 체스 게임의 설정을 임의로 변경하지 않습니다.

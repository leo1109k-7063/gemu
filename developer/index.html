개발자 센터

게임 놀이터의 개발자 전용 도구와 프로젝트 바로가기를 모아 둔 공간입니다.

현재 제공되는 기능에는 개발자 권한 확인, 코드 설명 문서, 계정별 루미큐브 컴퓨터 손패 공개 설정, 교사 관리 페이지 바로가기 등이 있습니다.

아래에서 실제 기능과 화면 확인용 페이지를 구분해서 확인할 수 있습니다.

개발자 설정

🧪 루미큐브 디버그 설정

현재 로그인한 개발자 계정으로 루미큐브를 실행할 때 컴퓨터가 보유한 타일을 확인할 수 있습니다.

이 설정은 개발자 계정별로 현재 브라우저에 저장됩니다. 다른 기기나 브라우저에는 자동으로 동기화되지 않습니다.

개발자 문서

📘 코드 설명 및 작동 원리 ↗

프로젝트 구조, 로그인 흐름, Supabase RPC, 권한 확인, 데이터 처리 방식과 보안상 주의점을 확인합니다. 새 탭에서 열립니다.
